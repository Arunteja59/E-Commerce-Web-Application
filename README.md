# E-Commerce-Web-Application

A modern and responsive E-Commerce Web Application developed to provide users with a smooth online shopping experience. The application allows users to browse products, add items to cart, manage orders, and securely place purchases.

---

## 🚀 Features

- User Registration and Login
- Product Listing and Search
- Add to Cart Functionality
- Order Management
- Secure Checkout
- Responsive Design
- Product Categories
- User Profile Management
- Admin Dashboard
- Real-Time Product Updates

---

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- React.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB
